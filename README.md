    # Assignment #1: HTML & CSS Basics

This repository contains the completed individual practical assignment for the Frontend Development course. The project consists of four interconnected web pages demonstrating fundamental HTML5 structure and CSS3 styling techniques, unified with a shared navigation bar.

## Project Structure

The project is organized into separate directories for each task, along with an assets folder for images:

    Task 1: Introduction to HTML & CSS (Personal Profile Card)

Description: A personal profile webpage introducing the author, built with HTML semantic elements and styled using CSS.
Requirements Met: Includes headings (h1, h2), paragraphs, an ordered list (ol), an unordered list (ul), an image with alt attributes, and external links with hover effects. Utilizes element, class, and ID selectors, custom fonts, margins, padding, and borders.

    Task 2: Simple Webpage Layout (Float-based Layout)

Description: A traditional multi-section webpage layout built using classical CSS float properties and div elements (without Flexbox or Grid).
Requirements Met: Features a header title, a navigation bar, a left sidebar menu with links, a right-side main content container (aside), and a footer with copyright information. Styled with distinct backgrounds, padding, and box shadows.

    Task 3: Tribute Page (Nikola Tesla)

Description: A dedicated biographical tribute page honoring the prominent inventor Nikola Tesla.
Requirements Met: Structured with main titles, subheadings, a life summary paragraph, life events (ol), and key contributions (ul). Styled with a subtle gradient background, imported Google Fonts, centered text containers, and a responsive portrait image.

    Task 4: CSS Table and Interactive Form

Description: A data presentation and user interaction page featuring a formatted student grades table and an interactive feedback form.

    Requirements Met:

Table: Contains multiple columns (Name, Subject, Grade), table headers, borders, cell padding, alternate row coloring via nth-child, cell merging (rowspan), and a custom-highlighted row (.highlight-row).

Form: Includes text inputs, email inputs, a role dropdown selection, radio buttons, message textarea, and a styled submission button with hover effects.
